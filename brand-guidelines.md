# Brand Guidelines: SKAT International Website

This document outlines the visual identity for SKAT's English-language web presence.

## 1. Color Palette
*   **Primary Color (Dark Grey/Black):** `#1C1D26`
    *   *Usage:* Main headings, logo text, primary navigation, structural lines, and icons.
*   **Accent Color (Vibrant Yellow):** `#FFB81C`
    *   *Usage:* Call-to-Action (CTA) buttons, hover states, highlighting key data points, decorative accent lines.
*   **Primary Background:** `#FFFFFF` (White)
    *   *Usage:* Main page backgrounds.
*   **Secondary Background:** `#F5F6F8` or `#EDEDF0`
    *   *Usage:* Section separators, card backgrounds, footer area.

## 2. Logo Usage
*   **Primary Logo:** Use the provided `СКАТ без б.png` file.
*   **Tagline:** Display "High-Voltage Test & Measurement Equipment" immediately below the logo in a smaller, grey font (e.g., `#333333`).
*   **Clearence:** Maintain a clear space around the logo equal to the height of the letter "S" to ensure visibility.

## 3. Typography
*   **Headings:** Use a modern sans-serif typeface (e.g., Roboto, Montserrat, Inter).
    *   *Weight:* Bold.
    *   *Color:* `#1C1D26`.
*   **Body Text:** Use the same sans-serif typeface.
    *   *Weight:* Regular.
    *   *Color:* `#333333`.
    *   *Line height:* 1.6 for readability.

## 4. Imagery
*   **Product Photography:** Use only real, high-resolution product photos.
    *   **General View:** The unit on a clean background.
    *   **Laboratory Use:** The unit in operation, connected to a test object (cable, oil cell, etc.).
    *   **Service/Maintenance:** A close-up of the unit with a technician or showing maintenance procedures.
*   **Style:** Maintain an industrial, clean, and professional aesthetic. Avoid stock photos of unrelated equipment.

## 5. UI Elements
*   **Buttons:** Use the accent color (`#FFB81C`) for primary CTA buttons with dark text (`#1C1D26`). Hover state should be slightly darker or shadowed.
*   **Icons:** Use solid, simple line icons where possible. Color them with `#1C1D26` or `#FFB81C` depending on the context.
*   **Tables:** Use a clean table design with light grey lines and clear headers. Data columns should be easily scannable.
