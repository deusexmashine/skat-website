About the product

The SKAT-70P is a specialized measuring attachment designed to work with high-voltage sources to perform leakage current tests on electrical Personal Protective Equipment (PPE). It allows for the testing of up to four items simultaneously, drastically reducing test time.

Its modular design allows for seamless integration with standard high-voltage test sets, making it a versatile and essential tool for any high-voltage safety laboratory. The system includes a test bath, control box, and a full set of interconnection cables.

FAQ

Up to four PPE items can be tested simultaneously, with independent leakage current measurement per channel.
The SKAT-70P is designed for use with SKAT-70M, SKAT-70C, and AID-70C series, as well as other high-voltage sources with appropriate control interfaces.
The system provides clear audio-visual signals for HV Active, Breakdown Detected, and Test Complete, ensuring operator awareness at all times.

Interpreting test results

For detailed guidance on PPE testing, refer to your equipment's user manual and the following standards:

  • IEC 60903 - Live working - Gloves of insulating material
  • IEC 61112 - Live working - Insulating blankets
  • ASTM F496 - Standard Specification for In-Service Care of Insulating Gloves and Sleeves

Troubleshooting & Software updates

  • No current readings: Check connections and ensure the test bath is properly grounded.
  • Inconsistent readings: Verify that the test objects are clean and properly positioned in the bath.
  • Communication error: Verify the cable connections between the control box and test bath.

This device does not require software or firmware updates. Contact technical support for any inquiries.
